# Флор

Офлайн-приложение для учёта флорбольных матчей кафедры.

Сайт: https://etotimoxa.github.io/flor/

- состав и распределение по красным и синим
- таймер, голы, пауза и сигнал в конце тайма
- журнал матчей
- Excel: сводка плюс отдельный лист-протокол на каждый матч
- общая база: игроки и матчи одни и те же на всех телефонах
- резервная копия JSON на устройстве

## iPhone

1. Откройте сайт в Safari, не в Chrome.
2. «Поделиться» → «На экран Домой».
3. Дальше заходите только с этой иконки.

Игроки и матчи общие для всех, кто открывает сайт. На iPhone данные ещё дублируются локально, поэтому стол работает и без сети. После игр можно скачать Excel из «Журнал» или JSON из «Ещё».

## Публикация

`npm run build`, папка `dist`. GitHub Pages поднимается workflow из `.github/workflows/pages.yml`.

```bash
npm install
npm run dev
npm test
npm run build
```
